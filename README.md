
# Student Performance Analytics System

## 1. Project Objective

The objective of this project is to analyze student academic
performance using Python, NumPy and Pandas.

The system calculates marks, averages, grades, pass/fail status,
subject-wise performance and identifies top-performing students.

## 2. Technologies Used

- Python
- NumPy
- Pandas
- Google Colab
- GitHub

## 3. Dataset Description

The dataset contains 20 student records.

The columns include:

- Student ID
- Name
- Department
- Python
- Mathematics
- Data Science
- AI
- Statistics
- Attendance

## 4. Project Features

1. Load student data from a CSV file.
2. Calculate total marks and average marks.
3. Assign grades to students.
4. Determine pass/fail status.
5. Calculate highest, lowest and class average.
6. Perform subject-wise analysis.
7. Identify the best and lowest-performing subjects.
8. Find the top three performers.
9. Analyze attendance.
10. Save the processed results to a CSV report.

## 5. Grading System

| Average Marks | Grade |
|---|---|
| 90 and above | A+ |
| 80 to below 90 | A |
| 70 to below 80 | B |
| 60 to below 70 | C |
| 50 to below 60 | D |
| Below 50 | F |

## 6. Pass/Fail Criteria

A student passes if every subject mark is at least 40
and attendance is at least 75%.

Otherwise, the student fails.
